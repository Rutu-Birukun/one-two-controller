# Power test plan

## Objective
Validate power stability, charging behavior, and runtime expectations.

## Checklist
- measure supply voltage under idle and active load
- verify USB charging path behavior
- confirm battery voltage remains safe during runtime
- check regulator thermal performance
- verify the device can operate while charging

## Pass criteria
- no unexpected voltage drops during audio playback
- battery and charging logic behave consistently
- thermal load remains within acceptable limits
