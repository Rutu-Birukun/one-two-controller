# One Two Controller

A public open design project for an MP3-based controller and playback hardware concept. This repository captures the brainstorm, hardware direction, firmware plan, BOM foundations, and design notes for iteration.

## Project Goal

Create a compact, flexible controller device with:
- personal audio playback capability
- a practical user interface
- straightforward firmware architecture
- modular hardware for easy iteration
- a well-documented BOM and design rationale

## Repository Layout

- `docs/` — requirements, architecture, and design decisions
- `bom/` — bill of materials and component notes
- `electronics/` — schematics, PCB, and test results
- `firmware/` — embedded firmware planning and source directory
- `mechanical/` — CAD/rendering notes
- `concepts/` — concept exploration and generated ideas
- `software/` — UI or host-side tooling
- `tests/` — validation and testing notes

## Current Status

This project is in concept/brainstorming stage. The goal is to capture ideas, narrow the feature set, and establish a practical platform for firmware and hardware development.

## Next Milestones

1. Confirm the target hardware architecture
2. Finalize the functional requirements
3. Build the BOM and compare candidate components
4. Define a baseline firmware stack
5. Validate power, audio, and control interfaces
6. Move from concept to prototype hardware

## Notes

This repository is meant to be updated as the design evolves. Keep major decisions in the docs and design notes rather than burying them in conversation history.
